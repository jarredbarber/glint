# Getting Started

Welcome to Glint! This is a quick start guide.

## Installation

Run `npm install -g glint` to install globally.

## Usage

```bash
glint serve /path/to/your/notes
```

## Features

- **Math Rendering**: Inline $E = mc^2$ and block equations
- **Themes**: Beautiful dark themes like Everforest
- **File Browser**: Navigate your notes easily
