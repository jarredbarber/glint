Glint Privacy Policy

Last updated 27 August 2026

Glint is a client-side static wiki with local folder, Google Drive, GitHub, and in-memory demo backends. There is no Glint server, user database, or analytics service.

What Glint accesses

  • The local folder backend reads and writes only the directory you select through your browser's File System Access API.
  • The Google Drive backend requests the drive.file scope. It can access files Glint creates and files or folders you authorize through Google Picker, then sends Drive operations directly to Google APIs.
  • The GitHub backend sends repository operations directly to the GitHub API using the OAuth token or fine-grained personal access token you provide.

What Glint stores

  • Google Drive and GitHub credentials are stored in your browser's local storage so reloads do not require another sign-in. Google access tokens are short-lived, typically about one hour. GitHub credentials remain until you sign out or clear this site's browser data.
  • Project preferences, source routes, and cached application state are also stored in the browser. Your Markdown content remains in the backend you selected.

Third-party services

Depending on the backend and features you use, your browser contacts Google APIs, GitHub, and the configured GitHub OAuth exchange service. It also downloads fonts and KaTeX styles from the jsDelivr CDN, which receives ordinary request metadata such as your IP address and browser headers. Glint does not send your Markdown documents to jsDelivr.

Removing access

Use Glint's sign-out controls or clear this site's browser data to remove locally stored credentials. You can revoke Google access from Google Account permissions and revoke GitHub access from your GitHub application or token settings.
